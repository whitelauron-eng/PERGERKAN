# Petualangan Kata! — Web Kuis Bahasa Indonesia Kelas IV

Website kuis interaktif untuk materi Bab II **Di Bawah Atap**.

## Isi folder
- `index.html` — struktur halaman dan tampilan aplikasi
- `style.css` — desain responsif untuk laptop dan ponsel
- `script.js` — bank soal, navigasi, penilaian pilihan ganda, ulasan, kisi-kisi, dan ekspor CSV

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser, atau unggah seluruh isi folder ke repository GitHub.
3. Aktifkan GitHub Pages melalui **Settings → Pages**.
4. Pada bagian Build and deployment, pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu simpan.
5. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat website.

## Fitur
- 20 soal pilihan ganda dan 5 soal isian.
- Input nama peserta didik.
- Navigasi soal dan indikator kemajuan.
- Skor otomatis pilihan ganda (maksimal 80 poin).
- Jawaban isian disiapkan untuk pemeriksaan manual guru (maksimal 20 poin).
- Halaman mode guru berisi kisi-kisi, kunci jawaban, dan pedoman penskoran.
- Ulasan jawaban dan unduh rekap jawaban dalam format CSV.

## Catatan penggunaan
- Website ini berjalan di browser tanpa server atau database.
- Jawaban tidak dikirim atau disimpan ke akun guru secara otomatis. Unduh CSV dari perangkat peserta didik jika ingin menyimpan rekap.
- Materi dan cakupan soal mengacu pada Bab II “Di Bawah Atap” dalam buku Panduan Guru Bahasa Indonesia: Lihat Sekitar untuk SD/MI Kelas IV (Edisi Revisi), khususnya kosakata, homonim, awalan `me-`, SPOK, kalimat majemuk setara, cerita, dan ide pokok.
- Pertanyaan isian perlu diperiksa guru agar penilaian tetap mempertimbangkan variasi jawaban yang benar.
